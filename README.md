# A Place for Recovery

A simple landing page that links out to a small set of recovery tools:

- **[Anchorpoint](https://sdangler99-cloud.github.io/Anchorpoint-recovery-main)** — sobriety tracking, gratitude journaling, and nightly reflection.
- **[Groundwork](https://sdangler99-cloud.github.io/Groundwork-main)** — breathing exercises, grounding tools, and a control checklist.
- **[God's Corner](https://sdangler99-cloud.github.io/faith-main/)** — devotionals, a prayer journal, and favorite verses.

## Files

- `get-the-apps.html` — the landing page. Open it directly, or enable GitHub Pages for this repo (Settings → Pages → Deploy from branch → `main`) to get a shareable link.
